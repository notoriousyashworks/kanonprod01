# Kicks Aura: Keyword Map

**Status:** intent-based starting map, applied to titles and copy. No search-volume or competition data was available when this was written, so **these terms are not validated**. Check them in Google Keyword Planner and in the Search Console Performance report once the site has 4–8 weeks of data, then refine.

**Rules used**
- One primary keyword per page, so pages don't compete with each other.
- Natural wording only; no keyword stuffing.
- No claims that aren't true of the store: nothing like "genuine", "authentic" or "original", and no brand-name targeting (see the brand decision in `final-seo-report.md`).
